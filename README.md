# Portfolio Website - UAS Cloud Computing

Website portofolio statis yang dikembangkan untuk memenuhi tugas Akhir Semester (UAS) mata kuliah Cloud Computing.

## 🚀 Live Demo
Website ini di-deploy menggunakan **GitHub Pages** dan dapat diakses pada link berikut:
👉 [Lihat Website Portofolio Live](https://syarif250505.github.io/Project_Portofolio_Sarif/)

## 🛠️ Fitur Utama
- **Responsive Web Design** (Tampilan menyesuaikan layar Desktop & Mobile)
- **Dark Mode / Light Mode Toggle**
- **Seksi Utama:** Beranda, Profil & Pendidikan, Portofolio Proyek, dan Kontak

## 💻 Tech Stack
- HTML5
- CSS3 (Custom CSS Variables)
- JavaScript (Vanilla JS)
- GitHub Pages (Deployment & Hosting)
